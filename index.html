How it works

From an image selected in the browser to structured analysis results.

01

Upload

The user chooses an image in the Flask interface.

02

Send request

Python sends image bytes and credentials to the Azure REST endpoint.

03

Analyze

Azure returns a JSON response containing available image features.

04

Present

Flask parses the response and renders readable results in the page.

Run it locally

Follow these steps from the project folder in VS Code or PowerShell.

1. Install dependencies

PowerShell / terminal
python -m pip install -r requirements.txt

2. Configure credentials

Create a local .env file next to app.py. Replace these placeholders with your Azure resource values.

.env template
VISION_ENDPOINT=https://YOUR-RESOURCE-NAME.cognitiveservices.azure.com VISION_KEY=YOUR_AZURE_KEY

3. Start Flask

Run the application
python app.py

Open http://127.0.0.1:5000, choose an image and click Analyze Image.

Security matters

Keep your cloud credentials separate from your public source code.

Never publish your Azure API key. Keep the actual values in a local .env file and make sure `.env` is listed in `.gitignore`. If a key is exposed, rotate it in Azure. The interactive GitHub Pages site is a static showcase only; it cannot securely call Azure using a secret key.

Learning outcomes

The project demonstrates the full path from cloud resource provisioning to user-facing results.

Cloud setup

Provision an Azure AI Vision resource and configure its endpoint and access key.

API integration

Send image data to a REST API, handle errors and parse JSON responses in Python.

Result interpretation

Read captions, tags, object confidence scores and OCR output with awareness that AI results can be imperfect.

Project hygiene

Track source code and documentation with Git while keeping credentials out of version control.
